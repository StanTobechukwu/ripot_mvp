Using this reporting structure

Technique and sampling

Describe the renal examination and vessels sampled, with technical limitations. Keep right and left renal measurements separate. For Doppler, document the sampled sites, velocity units and relevant angle-correction information.

Interpretation

PSV and EDV denote peak systolic and end-diastolic velocity. Record renal-aortic ratios and intrarenal resistive indices only from reviewed measurements, using the appropriate laboratory method. Ripot does not calculate these values or diagnose stenosis; explain incomplete assessment in the conclusion.

Documentation help, not clinical guidance. Use current specialty guidance and local protocols. Review every report before signing or sharing.
