Using this reporting structure

Gland and nodule records

Document gland dimensions and background appearance. Give each nodule a stable identifier, location and dimensions. The nodule fields separate composition, echogenicity, shape, margins and echogenic foci so the observations remain reviewable.

Classification and conclusion

If assigning a TI-RADS category, name the system used and verify the classification against that system. This template does not calculate a score or recommend biopsy. Record relevant lymph-node findings, comparison and the clinician’s conclusion separately.

Documentation help, not clinical guidance. Use current specialty guidance and local protocols. Review every report before signing or sharing.
