Using this reporting structure

Measurements and method

Document the study context, image quality and relevant comparison. Enter chamber measurements, systolic function and Doppler observations with the displayed units. State the method for measurements such as ejection fraction so that subsequent comparisons are meaningful.

Integrated impression

Use the valve, ventricular and pericardial findings to support a concise clinician-authored summary. Document technical limitations and incomplete measurements. This structure does not calculate function or grade disease from an isolated number.

Documentation help, not clinical guidance. Use current specialty guidance and local protocols. Review every report before signing or sharing.
